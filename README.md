# HTML Games

A browser-based game hub built with vanilla JavaScript, HTML, and CSS featuring interactive implementations of Chess and Tic-Tac-Toe.

## Games Included

### Chess (`chess.html`)
* **Interactive Board & Move Indicators:** Highlights legal destination squares on piece selection and prevents moves that leave the player's own king in check.
* **Full Rule Support:** Implements check and checkmate detection, stalemate draws, kingside/queenside castling, *en passant* captures, and interactive pawn promotion.
* **Match Controls:** Includes customizable player names, per-player countdown timers, captured piece displays, and live material advantage tracking.

### Tic-Tac-Toe (`tic_tac_toe.html`)
* Two-player local gameplay with automatic win/draw detection, persistent score tracking, and automatic board resets.

## How to Run
Open `index.html` in any modern web browser to select and play either game.

*Built as an early front-end development project to practice DOM manipulation and game state logic.*
